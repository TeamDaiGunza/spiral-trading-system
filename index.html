SETUP

Running in
4 steps.

You need a Kalshi account and an Anthropic API key. Everything else is included in the download.

01
KALSHI ACCOUNT
Sign up at kalshi.com. Go to ☰ → Account and Security Settings → API section → create your key pair.
02
ANTHROPIC KEY
Get a key at console.anthropic.com → API Keys → Create Key. Powers the AI signal engine. ~$1-5/month typical usage.
03
INSTALL
Run the installer. Enter your keys in System Initialization. Click Engage. Keys saved locally — enter once, never again.
04
ARM SYSTEM
Hit ARM SYSTEM. Tip: enable PAPER mode first to watch it trade risk-free for a session. When satisfied, switch to live. Fully autonomous either way.

FAQ

Common questions.

Is this actually free?
The app itself is free. To use it you need: a Kalshi account (free to open, 1% trading fee per winning trade), and an Anthropic API key (~$1-5/month for typical bot usage). No subscription, no hidden fees.
How much money do I need to start?
The bot is built for small accounts. $10-50 is a reasonable start. Kelly sizing scales naturally with your account as it grows.
Are my API keys safe?
Keys are stored locally in %APPDATA%\Spiral\ and sent only to Kalshi and Anthropic directly. The source code is open for inspection.
What markets does it trade?
BTC, ETH, SOL, XRP, and DOGE 15-minute prediction markets on Kalshi. Scans up to 12 markets simultaneously per cycle.
Can I trade manually while it runs?
Yes. The bot detects your manual positions and never interferes with them. Override, close early, or trade alongside it freely.
How do I get updates?
Updates are manual — there is no auto-update. Check this page or the GitHub releases link periodically. When a new version drops, download and run the new installer. The full changelog explains every change made.
