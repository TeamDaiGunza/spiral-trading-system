SETUP

Running in
4 steps.

You need a Kalshi account and an Anthropic API key. Everything else is included.

01
KALSHI ACCOUNT
Sign up at kalshi.com. Go to ☰ → Account and Security Settings → scroll to API section → create your key pair.
02
ANTHROPIC KEY
Get a key at console.anthropic.com → API Keys → Create Key. This powers the AI signal engine. ~$1-5/month typical usage.
03
INSTALL & CONNECT
Run the installer. Enter your keys in System Initialization. Click Engage. Keys saved locally — enter once, never again.
04
ARM SYSTEM
Hit ARM SYSTEM. The bot scans markets, evaluates 15 signals, confirms with dual AI, and places orders. Fully autonomous.

FAQ

Common questions.

Is this actually free?
Yes. The app itself costs nothing and always will. You pay Kalshi trading fees (1%) and Anthropic API fees (~$1-5/month for typical usage). That's it.
How much money do I need to start?
The bot is designed for small accounts. It trades with $1 minimum stakes and uses Kelly sizing to scale with your account. $10-50 is a reasonable starting point.
Is my API key safe?
Yes. Keys are stored locally on your machine in %APPDATA%\Spiral\ and are never sent anywhere except directly to Kalshi and Anthropic. The source code is open for inspection.
What markets does it trade?
BTC, ETH, SOL, XRP, and DOGE 15-minute and 1-hour prediction markets on Kalshi. It scans up to 12 markets simultaneously and picks the best signal.
Can I still trade manually while it runs?
Yes. The bot detects manual positions and never interferes with them. You can override, close early, or trade alongside the bot freely.
How do updates work?
The app checks GitHub Releases automatically every hour. When a new version is available it downloads in the background and installs on next launch. No action needed from you.
